## Для Claude Code

Готовый модуль: `design/ResourceIcons.luau`. Перенеси его в `ReplicatedStorage/RewardAds/ResourceIcons` как ModuleScript либо подключи через существующую структуру Rojo.

```lua
local Icons = require(game.ReplicatedStorage.RewardAds.ResourceIcons)
imageLabel.Image = Icons.chest
```

Имена ключей соответствуют PNG, а не обязательно внутренним ID ресурсов игры — сопоставь их с существующим инвентарём.
