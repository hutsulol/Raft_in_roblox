# Handoff: Табличка улучшения здания (Roblox, тема «Океан»)

## Overview
Компактный BillboardGui, который **всегда висит над каждой постройкой** игрока (~260×100 px):
- **золотая плашка с названием** постройки (наклон −2°, заходит на табличку на 9 px);
- **стеклянная табличка** с тремя элементами в ряд:
  - **уровень** («УР 2»);
  - **множитель прибыли** («×2»);
  - **кнопка с молотком и ценой** — нажатие сразу запускает улучшение, отдельного окна нет;
- во время **сборки** на месте кнопки появляется полоса прогресса с процентом;
- на **максимальном уровне** кнопки нет, а значок уровня становится золотым.

## About the Design Files
`Улучшение здания.dc.html` — **HTML-референс** (открывается в браузере, рядом нужен `support.js`). На скриншоте игры есть живая табличка, а ниже собраны 4 состояния.
`src/` — **готовые Luau-исходники**. Их нужно разложить по сервисам, вставить ID ассетов, повесить тег на постройки и подключить свою валюту и сохранение (места помечены `TODO`). Если в проекте свой UI-фреймворк, перенесите на него.

## Fidelity
High-fidelity: цвета, размеры и раскладка финальные. Молоток и монета в `assets/` — простые иконки, сгенерированные под макет. Их можно заменить на иконки игры того же размера.

## Импорт по шагам

### 1. Ассеты → ID
Creator Hub → Images (или Asset Manager → Bulk Import):
| Файл | Размер | Назначение |
|---|---|---|
| `assets/hammer.png` | 128×128 | иконка молотка в кнопке (24 px в UI) |
| `assets/coin.png` | 64×64 | монета перед ценой (15 px) |
| `assets/pointer.png` | 64×36 | белый треугольник-указатель вниз (красится ImageColor3) |

Вставить ID в `src/Assets.lua`.

### 2. Скрипты
| Файл | Куда | Тип |
|---|---|---|
| `src/BuildingUpgradeData.lua` | ReplicatedStorage → **BuildingUpgradeData** | ModuleScript |
| `src/Assets.lua` | ReplicatedStorage → **BuildingUpgradeAssets** | ModuleScript |
| `src/BuildingUpgradeServer.server.lua` | ServerScriptService → **BuildingUpgradeServer** | Script |
| `src/BuildingUpgradeBillboard.client.lua` | StarterPlayerScripts → **BuildingUpgradeBillboard** | LocalScript |

### 3. Разметить постройки
У каждой постройки (Model, лучше с PrimaryPart) должны быть:
- тег CollectionService **`UpgradableBuilding`**;
- атрибуты:
  - `BuildingName` (string) — например, «Домик фермера»;
  - `Level` (number, 0–5);
  - `OwnerUserId` (number);
  - `Building` (bool) — ставит сервер;
  - `BuildStart` (number) — ставит сервер.

Клиент сам находит постройки по тегу и вешает табличку. Она обновляется при изменении атрибутов и баланса монет.

### 4. Подключить экономику
- **Валюта:** по умолчанию берётся `leaderstats.Coins`, функция `getCoins` на сервере и функция `coins()` на клиенте. Замените на свою систему.
- **Прибыль:** там, где считается доход здания и рабочих в нём, умножайте на `Data.Mults[model:GetAttribute("Level")]`.
- **После сборки** (`TODO` на сервере): сохранить уровень и при желании сменить модель здания на версию следующего уровня.

## Спецификация (px)
- **BillboardGui:** 260×100, `StudsOffsetWorldSpace` = (0, высота модели / 2 + 3, 0), `AlwaysOnTop`, `MaxDistance` 60, `LightInfluence` 0
- **Плашка названия:** градиент `#FFE38A → #F5B73C`, обводка 3 `#0D2A4F`, радиус 12, padding 3/16/5/16, Rotation −2. Текст 17, белый, UIStroke 2,5 `#0D2A4F`
- **Табличка:** градиент `#1F4F8F → #143A6B`, прозрачность 0,15, обводка 3 `#A9D6F7`, радиус 16, padding 5, gap 6
- **Уровень** 40 px в высоту: градиент `#54A7EC → #3A7FD0`, обводка 3 `#1C4F8F`, радиус 11. «УР» 10 px `#CFE6FA` + цифра 20 px белая. На макс. уровне: `#FFE38A → #F5B73C` / `#B07A14`
- **Множитель:** 24 px `#FFD95A`, UIStroke 3 `#0D2A4F`. Формат `×1,5` (через `Data.FormatMult`)
- **Кнопка** 40 px в высоту, радиус 11, padding 0/10/0/6: молоток 24 + монета 15 + цена 15 px
  - хватает монет: градиент `#6FF08A → #34B84E`, обводка `#1F7A33`, цена белая, красный бейдж «!» 16 px в правом верхнем углу
  - не хватает: `#2E6BB4`, обводка `#1C4F8F`, цена `#FF8A7E`, без бейджа, нажатие игнорируется
  - нажатие: scale 0,92 → 1 (0,08 c + 0,15 c Back)
- **Сборка:** 96×40, трек `#143A6B`, обводка 3 `#0D2A4F`, заливка `#FFE38A → #F5B73C`, процент 14 px. Прогресс считается от `BuildStart` по серверному времени
- **Указатель:** 18×10, цвет `#143A6B`

## Уровни (пример, `BuildingUpgradeData.lua`)
| Уровень | Множитель | Цена перехода на следующий |
|---|---|---|
| 0 | ×1 | 500 |
| 1 | ×1,5 | 1 500 |
| 2 | ×2 | 4 000 |
| 3 | ×3 | 10 000 |
| 4 | ×4,5 | 25 000 |
| 5 | ×6 | — (макс.) |

Сборка длится 2 c (`BuildTime`).
