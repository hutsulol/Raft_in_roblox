# Редизайн UI игры — план

Переносим прототип (Claude Design) в Roblox. Подход: **единый дизайн-модуль**
`ReplicatedStorage/UITheme` со спекой стиля + палитрами тем, через него собираем
каждый экран. Так дизайн консистентный и правки делаются в одном месте.

## Спека стиля (из скринов)
- Панель: `UICorner 18`, `UIStroke 4px` тёмным тоном темы.
- Кнопка: `UICorner 12`, `UIStroke 3px` + «грань» снизу (Frame 5px, чёрный 18%),
  hover масштаб 1.05 за 0.1с.
- Слот: `UICorner 12`, `UIStroke 3px`; пустой — заливка 35% прозрачности.
- Активная вкладка — золотая: `#FFD95A→#F5B73C`, рамка `#B07A14`.
- Текст: Builder Sans Bold / GothamBlack, белый, тень.
- Цена-пилюля: хватает `#4CD964`, не хватает `#FF6B5A`.

## Фазы (пошагово, с твоим ревью после каждой)
- **Фаза 0 — Фундамент** ✅ `UITheme` модуль: палитры, константы, фабрики
  (panel / button / slot / tab / pricePill / hover / иконобокс / текст-с-тенью).
- **Фаза 1 — Уведомления** ✅ `NotificationCenter` в новом стиле (карточки по типу:
  info/unlock/success/reward/warn), выезд сбоку, авто-исчезание; `_G.Notify(...)`.
- **Фаза 2 — Инвентарь + хотбар** — переодеть `InventoryUI` (сетка 5×3, валюты в
  шапке, заблокированный ряд «Need Strength»).
- **Фаза 3 — Крафт** — переодеть `WorkbenchUI` (категории слева, рецепты справа,
  цена-пилюли, кнопка Craft зелёная/серая).
- **Фаза 4 — Строительство** — переодеть `BuildingSystem` UI (вкладки Floors/Walls,
  карточка блока, подсказка в углу).
- **Фаза 5 — Зачистка** — пройтись по остальным попапам (склад/печь/контейнеры)
  для единого стиля; вынести квест-уведомления на `_G.Notify`.

## Принципы переноса существующих экранов
- Логику (данные, RemoteEvents, рецепты, размещение блоков) НЕ трогаем — меняем
  только визуальный слой: создание/стилизацию инстансов гоним через `UITheme`.
- Каждую фазу — отдельным коммитом; после правок block-balance проверка.
