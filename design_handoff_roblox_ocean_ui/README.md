# Handoff: Roblox UI «Океан» — магазин торговца, яйца-кейсы, индикатор подбора

## Overview
Набор игровых интерфейсов для Roblox-игры про выживание на плоту (Pirate Island) в едином синем стиле «Океан»:
1. **Магазин странствующего торговца**: торговец приплывает на время, у него есть особое предложение и товары с лимитом штук.
2. **Индикатор подбора предметов**: тосты справа снизу.
3. **Подсказка у яйца**: ProximityPrompt «E — Открыть яйцо».
4. **Панель над яйцом**: BillboardGui с шансами выпадения питомцев.
5. **Окно покупки яйца**: модалка ScreenGui.

Стиль совпадает с уже существующими окнами крафта и инвентаря (файл `Инвентарь и крафт Cartoon.dc.html`, тема «Океан»).

## About the Design Files
Файлы в этом пакете — **дизайн-референсы в HTML**. Это прототипы, которые показывают внешний вид и поведение, а не продакшн-код. Задача — **пересобрать их в Roblox Studio** (ScreenGui / BillboardGui / ProximityPrompt + Luau-скрипты) по принятым в проекте паттернам. Если в проекте есть UI-фреймворк (Roact/React-lua, Fusion), используйте его. Если нет, стройте на обычных Instance.
HTML открывается в браузере напрямую (рядом нужен `support.js`). Все стили в файлах инлайновые: значения можно брать прямо из разметки.

## Fidelity
**High-fidelity.** Цвета, радиусы, обводки, размеры и тексты финальные. Воспроизводить 1-в-1.
Исключение: **иконки предметов, портрет торговца, питомцы и яйцо** — это заглушки (полосатые квадраты или простые CSS-фигуры). Вместо них ставятся существующие 3D-рендеры игры (ImageLabel / ViewportFrame).

Размеры в px даны для экрана 1920×1080. В Roblox используйте `UIScale` или Scale-размеры и `UIAspectRatioConstraint`, чтобы UI масштабировался.

## Общий визуальный язык (маппинг CSS → Roblox)
- **Шрифт:** в макетах Nunito 800–900. В Roblox: `Enum.Font.FredokaOne` или `BuilderSansExtraBold`. Весь текст жирный.
- **Белый текст с тенью** (`text-shadow: 0 2px 0 rgba(0,0,0,.3)`): `UIStroke` (ApplyStrokeMode=Contextual, Color #000, Transparency 0.7, Thickness 1.5–2) либо дубль-TextLabel со смещением Y+2, чёрным цветом и Transparency 0.7.
- **Градиент окна** `#54A7EC → #3A7FD0` сверху вниз: `UIGradient`, Rotation 90.
- **Толстая обводка:** `UIStroke` ApplyStrokeMode=Border, Thickness 3–4.
- **«3D-кнопка»** (`inset 0 -4/-5px 0 rgba(0,0,0,.18)`): внутри кнопки у низа лежит Frame высотой 4–5 px, чёрный, Transparency 0.82, с тем же UICorner. При нажатии кнопка сдвигается на 2 px вниз.
- **Тень окна** (`0 10px 24px rgba(0,0,0,.3)`): ImageLabel с 9-slice тенью под окном (опционально).
- **Стекло** (billboard / prompt): Frame #1F4F8F, BackgroundTransparency ≈0.38 (панель) или ≈0.22 (prompt). backdrop-blur в Roblox не нужен.

### 2. Индикатор подбора — `Индикатор подбора предметов.dc.html`
Рекомендуемый вариант — **A** (плашки). Варианты B (чипы) и C (слоты) оставлены для выбора.
- Контейнер: AnchorPoint (1,1), Position {1,−24},{1,−150} (над хотбаром). UIListLayout снизу вверх, выравнивание вправо, Padding 10. Не больше 4 тостов, старые с Transparency 0.45
- Тост: градиент окна, обводка 3 `#1C4F8F`, радиус 14, высота ~62, padding 8/16/8/8, gap 12, AutomaticSize X
- Слот 44×44 (`#A9D6F7 → #8FC3EC`, обводка 3 `#2E6BB4`, радиус 10) · «+N» (20, `#FFD95A`) · название (17, белый)
- **Новый предмет** (первый подбор): обводка `#B07A14`, золотое свечение, бейдж «NEW!» на верхней кромке
- Поведение: один предмет — один тост. При повторном подборе N суммируется, счётчик делает «bounce» (scale 1 → 1.25 → 1 за 0.2 c), таймер жизни сбрасывается. Въезд X+400 → 0 за 0.35 c (Back/Out). Живёт 2.5 c. Уход: fade и сдвиг вниз за 0.25 c (Quad/In)

## Interactions & Behavior
- **Покупка в магазине:** клик → RemoteFunction `Merchant:Buy(itemId)` → сервер проверяет монеты, лимит и что торговец ещё здесь → ответ. На клиенте обновляются баланс и остаток, срабатывает индикатор подбора (+1 предмет). В прототипе всё считается локально, в игре **вся валидация серверная**
- **Состояния кнопки:** доступна (зелёная) · «Мало» (серая, coins < price) · «Продано» (серая, stock = 0). Нажатие — сдвиг на 2 px вниз
- **Вкладки:** фильтр по category. Особое предложение видно в «Все» и «Редкое»
- **Таймер:** обратный отсчёт с сервера (`workspace:GetServerTimeNow()` + `departAt`). На 0 окно закрывается, лодка уплывает
- **Открытие окна:** ProximityPrompt у лодки «E — Торговать». Анимация окна: scale 0.9 → 1 + fade, 0.2 c, Back/Out
- **Закрытие:** ✕, Esc/B, выход из зоны промпта

## State Management
Сервер (источник истины):
- `merchant.present: bool`, `merchant.departAt: number`
- `merchant.offers: {id, price, oldPrice?, featured?, category, rarity, stockPerPlayer}` — случайная выборка из пула при каждом прибытии, одна позиция featured
- `purchases[userId][itemId]: number` — сколько уже куплено (остаток = лимит − куплено)
- Баланс монет игрока

Клиент:
- `activeCategory` («Все» по умолчанию), `coins` (реплицируется), `offers` + остатки (реплицируются при открытии и после покупки)

Прототип хранит локально: `coins` 520, `left` 272 с, `cat`, `featured`, `stock{}`.

## Assets
- Иконки предметов, портрет торговца, питомцы, яйцо — **заглушки**, их заменяют существующие рендеры или модели игры
- Скриншоты в `uploads/` нужны только как фон для превью «в контексте игры»
- Шрифт Nunito (Google Fonts) используется только в HTML, в Roblox заменяется (см. выше)
