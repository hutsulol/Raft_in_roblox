# Handoff: Квест-трекер (Quest Tracker HUD) — Roblox

## Overview
Компактный HUD-виджет активного квеста в верхнем левом углу экрана. Без панели-подложки — чистый текст с чёрной обводкой поверх игры + тонкий прогресс-бар. Появляется, когда у игрока есть отслеживаемый квест.

## About the Design Files
`Quest Tracker Roblox.dc.html` — дизайн-референс в HTML (открывать в браузере, рядом `support.js`). Тёмный фон в файле — имитация игры, в Roblox его нет. Реализация: ScreenGui, прозрачный Frame (AnchorPoint 0,0; Position ~0.02, 0.03).

## Структура
1. **Строка заголовка** (flex-ряд, gap 9px):
   - Название квеста: «Постройте 5 полов» — шрифт жирный округлый (в HTML M PLUS Rounded 1c 900; в Roblox: **Enum.Font.FredokaOne** для латиницы/цифр, для кириллицы GothamBlack или кастомный шрифт), 23px, белый, чёрная обводка со всех сторон (UIStroke Thickness ≈2.5, Color #000) + лёгкая тень вниз.
   - Иконка «?»: 26×26px, синий #4a90dc, рамка 2px #000, скругление 8px, тень-подложка снизу 2.5px, белый «?» 900 с тенью. Кликабельна (открывает описание квеста).
2. **Ряд прогресса** (gap 10px, отступ сверху 8px):
   - Бар: высота 13px, фон rgba(0,0,0,0.55), рамка 2px #000; заливка — зелёный вертикальный градиент #6fdc5f → #35b435 → #1f7a24, ширина = progress/total (в Roblox Tween Size при изменении).
   - Счётчик «2/5»: та же гарнитура 900, 20px, белый с чёрной обводкой.

## State / Props
- `title: string` — название квеста.
- `progress: number`, `total: number` — прогресс; бар и счётчик обновляются с сервера (RemoteEvent при событии квеста), заливку твинить ~0.35s.
- Клик «?» → показать подсказку/описание квеста.
- Общая ширина виджета ~300px.

## Files
- `Quest Tracker Roblox.dc.html` — эталон (открывать в браузере)
- `support.js` — рантайм для прототипа (в Roblox не нужен)
