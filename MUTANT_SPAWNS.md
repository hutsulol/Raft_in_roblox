# Ползун: точки появления

Создай Part с точным именем `Mutant_1` внутри острова в Workspace, на уровне пола.
Верхняя поверхность парта задаёт уровень появления, поворот парта — направление взгляда.
Скрипт ищет точки на любой глубине вложенности и подхватывает острова, добавленные во время игры.
На каждой точке появляется один Ползун. В игре парт становится невидимым и не мешает движению.
При удалении острова соответствующий Ползун удаляется.

По умолчанию после смерти повторного появления нет. Для повторного появления добавь
парту числовой атрибут `RespawnSeconds`, например `30`: отсчёт начнётся после удаления тела.
Атрибут `SpawnEnabled=false` запрещает следующее появление, не удаляя уже живого моба.

Размести и назови точки до запуска игры либо клонируй остров с уже названными точками.
Шаблоны островов в ServerStorage не вызывают появление мобов до переноса в Workspace.

Файлы:
- `src/ServerScriptService/MutantCrawler.server.lua` — появление и поведение.
- `src/StarterPlayerScripts/MutantCrawler.client.lua` — анимации, лицо, звук, эффекты.
- `src/ReplicatedStorage/MutantCrawlerPack` — модель, клипы и настройки.

Принудительная атака царапанием из лаборатории отключена. Используются вероятности из
`CrawlerConfig.lua`: царапание 10%, максимум один раз за жизнь; два плевка 70/30.
Для аудио опыт должен иметь доступ к ассетам `75803387404969` и `137806382070660`.
Синхронизируй папку через существующий Rojo-проект. Основной плейс автоматически не публикуется.
