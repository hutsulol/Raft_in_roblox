# Handoff: Диалоговое окно NPC (Roblox-игра про плот)

## Overview
UI-система диалога с NPC для survival-игры на плоту (Roblox): окно диалога над панелью инвентаря с аватаркой говорящего, посимвольной печатью текста, наградами («Получено» с иконками предметов), вопросами с вариантами ответов и ветвлением. Плюс переработанный счётчик дня/ночи с анимированной сменой солнца/луны.

## About the Design Files
Файлы в этом пакете — **дизайн-референсы, созданные в HTML**. Это прототип, показывающий внешний вид и поведение, а НЕ production-код. Задача — **воссоздать этот дизайн в целевой среде игры** (для Roblox: Luau + Roblox GUI-объекты — ScreenGui, Frame, TextLabel, ImageLabel, UICorner, UIStroke, TweenService), следуя её паттернам. HTML напрямую не встраивается.

## Fidelity
**High-fidelity**: финальные цвета, типографика, отступы и интеракции. Воспроизводить точно, используя средства движка.

## Interactions & Behavior
- **Печать текста**: посимвольно, 30 мс/символ (настраиваемо 10–80), с курсором «▌» в конце печатающейся строки.
- **Клик по диалогу во время печати** → текст мгновенно допечатывается.
- **Клик по диалогу после допечатки** → следующая реплика (заново запускается печать).
- **Мигание-подсказка**: через 5 секунд после допечатки текст реплики начинает мигать (opacity 1 → 0.3 → 1, цикл 1.2s ease-in-out), пока игрок не кликнет.
- **Реплика-вопрос**: после допечатки появляются кнопки ответов (pop-анимация ~0.35s); клик по фону диалога дальше НЕ переключает — обязателен выбор ответа; каждый ответ ведёт на свою реплику (ветвление).
- **Награды**: у реплики может быть 1–3 предмета; плашка «Получено» появляется в момент допечатки с пружинной pop-анимацией (scale 0.4→1 + translateY 24px→0, 0.45s, easing overshoot cubic-bezier(0.34,1.56,0.64,1)); скрывается при переходе к следующей реплике.
- **Смена дня/ночи**: солнце и луна меняются перекрёстно — уходящая иконка opacity→0, rotate −120°, scale 0.3; приходящая наоборот; текст «День»/«Ночь» — кроссфейд со сдвигом по вертикали ±16px; всё 0.7s, transform с overshoot cubic-bezier(0.34,1.56,0.64,1).

## State Management
- `lineIndex` — текущая реплика; `chars` — сколько символов напечатано; `done` — допечатана ли; `blink` — мигает ли подсказка.
- Таймеры: интервал печати (мс/символ), таймаут 5с до мигания. Оба сбрасываются при смене реплики; чистить при закрытии диалога.
- Структура данных реплики: `{ text: string, rewards?: [{name, icon}], question?: [{label, next}], next?: number }`. Переход: выбранный ответ → `next` варианта; иначе `next` реплики или следующая по порядку.

## Design Tokens
- Голубой акцент: **#8ecdf6** (имя NPC, «ПОЛУЧЕНО», обводки иконок наград); приглушённый: rgba(142,205,246,0.95).
- Белый текст: #ffffff; тени текста: 0 2px 0 rgba(20,60,100,0.5) + 0 4px 12px rgba(0,0,0,0.35).
- Тёмная подложка: rgba(40,44,50,0.45–0.55), radius 12px (плашка) / 999px (пилюли).
- Кнопки: градиент #7a5430→#4a3018, hover #8a6238→#58391d, рамка #241609.
- Шрифты: **Russo One** (имена, «День N», названия предметов), **Nunito 700–900** (текст реплик, кнопки). В Roblox подобрать ближайшие (например, встроенные жирные шрифты).
- Скорость печати: 30 мс/символ; задержка мигания: 5000 мс; blink-цикл: 1.2s.
