# Handoff: Попап «Продажа улова» (Roblox, тема «Океан»)

## Overview
Попап без подложки, который появляется при продаже рыбы. Сверху вниз:
**свечение цвета редкости** (лучи крутятся, центр пульсирует) с **вращающимся рендером рыбы** → **вес** (белая плашка) → **название** (цвет редкости, ширина = ширине строки прибыли) → **прибыль** «+X,XX» с монетой pirate.

Экономика: выручка = вес × коэффициент рыбы, ограничена 0,5–15 pirate. 90% уловов дают 0,5–2, выше 5 — только 0,1%.

## About the Design Files
`Продажа улова.dc.html` — **HTML-референс** (прототип внешнего вида и поведения). Открывается в браузере, рядом нужен `support.js`. Кнопки «Поймать рыбу» и «Симуляция ×10 000» показывают распределение выручки.
Папка `src/` — **готовые Luau-исходники** под Roblox. Их нужно положить в нужные сервисы, проставить ID ассетов и подключить к механике продажи в проекте. Если в проекте свой UI-фреймворк или своя система валюты, адаптируйте под них.

## Fidelity
High-fidelity: цвета, размеры, тайминги и раскладка финальные. Рендеры рыб — **заглушки**: каждой рыбе нужен свой PNG (прозрачный фон, рыба боком, ~512×512).

## Импорт в игру (по шагам)

### 1. Загрузить картинки → получить ID
Creator Hub → Creations → Development Items → **Images** (или Asset Manager в Studio → Bulk Import):
| Файл | Назначение |
|---|---|
| `assets/glow_rays.png` | белые лучи с радиальным затуханием, 512×512, красятся через `ImageColor3` |
| `assets/glow_soft.png` | мягкое белое пятно для пульса, 512×512, красится через `ImageColor3` |
| `assets/coin_pirate.png` | монета pirate (круг с золотым кольцом), 256×256 |
| рендеры 13 рыб | ваши PNG (в пакете их нет) |

Вставить полученные ID:
- `src/Assets.lua` → `GlowRays`, `GlowSoft`, `CoinPirate`
- `src/FishData.lua` → поле `image` у каждой рыбы (`"rbxassetid://123..."`)

### 2. Разложить скрипты
| Файл | Куда | Тип |
|---|---|---|
| `src/FishData.lua` | ReplicatedStorage → **FishData** | ModuleScript |
| `src/Assets.lua` | ReplicatedStorage → **FishSellAssets** | ModuleScript |
| `src/FishSellPopup.client.lua` | StarterPlayer → StarterPlayerScripts → **FishSellPopup** | LocalScript |
| `src/FishSellServer.server.lua` | ServerScriptService → **FishSellServer** | ModuleScript (возвращает `SellFish(player)`) |

Если в проекте Rojo — суффиксы `.client.lua` / `.server.lua` уже подходят. Для FishSellServer переименуйте в `.lua`, если используете его как модуль.

### 3. Подключить
- В месте, где игрок продаёт улов (сервер): `local SellFish = require(ServerScriptService.FishSellServer)` → `SellFish(player)`.
- Начисление валюты: в `SellFish` стоит TODO — по умолчанию прибавляется к `leaderstats.Pirate`; замените на свою систему.
- Клиент сам слушает `ReplicatedStorage.Remotes.FishSold (fishId, weight, pay)`.
- **Ролл только на сервере.** Клиент лишь показывает результат.

## Спецификация попапа (px @1080p, масштабировать UIScale)
- **Позиция:** AnchorPoint (0,1), `{0,40},{1,-230}` — слева над полосками здоровья, не перекрывает HUD и персонажа
- **Сцена** 240×180:
  - лучи 260×260 (`GlowRays`, ImageColor3 = цвет свечения), Rotation 360° за `spin` секунд
  - пульс 195×195 (`GlowSoft`), scale 0.82 ↔ 1.12, прозрачность 0.45 ↔ 0, период 1.6 c
  - рыба 150×150, ScaleType Fit. Вращение вокруг Y (сжатие ширины по |cos|) + подскок −6 px, оборот 3.2 c
- **Вес:** белая pill, обводка 3 px `#0D2A4F`, текст 22 px `#0D2A4F`, формат `3,19 кг`
- **Название:** FredokaOne, базовый размер 30, цвет текста редкости, UIStroke 3 `#0D2A4F`. TextSize подгоняется так, чтобы ширина названия = ширине строки прибыли (clamp 10–60)
- **Прибыль:** `+2,39` — 42 px `#FFD95A`, UIStroke 4 `#0D2A4F`. Справа монета 40×40, отступ 6
- **Тайминг:** pop-in UIScale 0.3 → 1 за 0.45 c (Back/Out) · показ 2.6 c · уход Scale → 0 за 0.2 c (Quad/In). Новая продажа во время показа перезапускает попап
