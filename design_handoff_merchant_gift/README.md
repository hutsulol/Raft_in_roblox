# Handoff: Магазин торговца — режим «Только подарок» (Roblox)

## Overview
Когда у торговца **ровно одно предложение, и это бесплатный подарок**, правая панель «Предложения» не показывает одну узкую строку с кнопкой «Купить» и ценой 0. Вместо этого вся свободная зона занята **большой золотой карточкой подарка**:
- **красная лента «ПОДАРОК ТОРГОВЦА»** на верхней кромке;
- **крупный рендер** подарка, за ним медленно вращаются белые лучи;
- **название** крупно и **описание** под ним;
- **большая зелёная кнопка «Забрать бесплатно»**, после выдачи — «Получено» (неактивная);
- подпись **«Только 1 раз»**.

В сайдбаре вместо пустой золотой вкладки остаётся одна активная вкладка **«Подарок»**. Шапка (баланс, ✕), портрет и таймер не меняются.

## About the Design Files
`Магазин торговца.dc.html` — HTML-референс. Нужный раздел — **«Когда у торговца только подарок»** (ниже основного окна). Кнопка в превью кликается и возвращается через 2 с.
`src/` — Luau-модуль карточки и пример встраивания в существующий скрипт окна торговца. Окно торговца в игре уже есть; задача — **добавить второй режим рендера**, а не переделывать окно.

## Fidelity
High-fidelity: цвета, размеры и раскладка финальные. Рендер подарка — ваш ассет (на скриншоте это «Рыбацкое место»), рекомендуемый размер 512×384, прозрачный фон.

## Что сделать

### 1. Ассет
Загрузить `assets/gift_rays.png` (белые лучи 512×512) → вставить ID в `src/Assets.lua` (ReplicatedStorage → **MerchantGiftAssets**).

### 2. Модуль
`src/GiftCard.lua` → ModuleScript **GiftCard** рядом с клиентским скриптом окна торговца.

### 3. Логика выбора режима
См. `src/Integration.client.lua`:
```lua
local function isGiftOnly(offers)
  return #offers == 1 and offers[1].isGift == true and (offers[1].price or 0) == 0
end
```
- `true` → скрыть список строк и «особое предложение», вызвать `giftCard:Set(offer, onClaim)`, в сайдбаре оставить вкладку «Подарок».
- `false` → `giftCard:Hide()`, обычный список и вкладки.
- Карточка — дочерний Frame `Size = UDim2.fromScale(1, 1)` контейнера под шапкой «Предложения»; она растягивается на всю свободную высоту.

### 4. Данные предложения
Добавить в предложение торговца поля:
| Поле | Тип | Пример |
|---|---|---|
| `isGift` | bool | `true` |
| `price` | number | `0` |
| `name` | string | «Рыбацкое место» |
| `description` | string | «Рыбак ловит рыбу и продаёт улов» |
| `image` | string | `rbxassetid://…` (рендер подарка) |
| `claimed` | bool | реплицировать с сервера, если игрок уже забрал |

### 5. Сервер
Существующий `MerchantBuy` (или аналог) должен:
- принимать `price == 0` для `isGift`;
- проверять «1 раз на игрока» и сохранять это;
- выдавать подарок (здание / персонажа).

После `ok` клиент вызывает `giftCard:SetClaimed(true)`. Повторные клики игнорируются.

## Спецификация (px @1080p)
- **Карточка:** вся область под шапкой, градиент `#FFE38A → #F7C24E`, обводка 4 `#B07A14`, радиус 18, padding 22/18/18/18, вертикальный список по центру, gap 12
- **Лента:** «ПОДАРОК ТОРГОВЦА», 13 px, белая, фон `#E84A3A`, обводка 3 `#A82E2E`, pill, по центру верхней кромки (центр на −15 px)
- **Сцена:** растягивается на остаток высоты (UIFlexItem Fill, минимум 170)
  - лучи 300×300, белые, прозрачность 0,25, оборот за 12 c
  - слот рендера 210×150, фон `#FFF3C9`, обводка 4 `#B07A14`, радиус 18. Рендер внутри — ScaleType Fit, отступ 8
- **Название:** 28 px, белое, UIStroke 3 `#7A4F06`
- **Описание:** 14 px, `#7A4F06`, ширина до 420, перенос строк
- **Кнопка** 320×52, радиус 14, текст 21 px белый:
  - активная: градиент `#6FF08A → #34B84E`, обводка 3 `#1F7A33`, внешнее белое кольцо 3 px
  - «Получено»: фон `#C9A45A`, обводка `#9A7A32`, текст `#FFF6DC`, без кольца
- **Подпись:** «Только 1 раз», 12 px, `#7A4F06`
- **Сайдбар:** одна вкладка «Подарок» в активном золотом стиле (`#FFD95A → #F5B73C`, обводка `#B07A14`)
