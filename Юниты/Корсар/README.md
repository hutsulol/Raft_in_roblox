# Корсар

Путь в репозитории: `Юниты/Корсар`.

Папка содержит актуальный серверный скрипт для NPC Корсара в Roblox Studio.

## Файлы

- `CorsairAI.server.lua` — единый скрипт для физики, коллайдеров, анимаций, преследования игрока и атаки.

## Как вставить в Roblox Studio

1. В модели Корсара оставь структуру:

   ```text
   Corsair
   ├─ Script
   ├─ BodyColliders
   │  ├─ HeadCollider
   │  ├─ LeftLegCollider
   │  ├─ LeftHandCollider
   │  ├─ RightHandCollider
   │  ├─ RightLegCollider
   │  └─ TorsoCollider
   ├─ corsair
   ├─ AnimationController
   │  └─ Animator
   ├─ Idle
   ├─ Walk
   ├─ Run
   └─ Attack
   ```

2. Скопируй содержимое `CorsairAI.server.lua` в обычный серверный `Script` внутри модели Корсара.
3. У объектов `Idle`, `Walk`, `Run`, `Attack` должны быть выставлены правильные `AnimationId`.
4. Отключи старые скрипты, которые отдельно приваривали коллайдеры, запускали анимации или двигали Корсара, чтобы не было конфликтов.

## Логика поведения

### Здоровье (HP) без Humanoid

В модель **не нужно** добавлять `Humanoid`. Он ломает этот тип юнита:

- перехватывает анимации у `AnimationController` (у модели должен быть либо
  `Humanoid`, либо `AnimationController`, но не оба сразу) — анимации перестают играть;
- запускает свою физическую state-machine поверх ручного движения
  (`AssemblyLinearVelocity`, `AlignOrientation`, велды) — ломается физика.

Поэтому HP сделано без Humanoid. Если `Humanoid` остался от старых
экспериментов, скрипт сам удалит его при запуске.

- Стартовое HP задаётся константой `UNIT_MAX_HEALTH = 100` в начале скрипта.
- Здоровье хранится в **атрибутах модели**: `Health` и `MaxHealth` (видны во
  вкладке Attributes и реплицируются на клиент — удобно для полоски HP).
- Урон/лечение из других скриптов — через `BindableFunction` внутри модели:
  - `model.TakeDamage:Invoke(20)` — нанести 20 урона (возвращает остаток HP);
  - `model.Heal:Invoke(10)` — вылечить на 10.
- Можно менять `Health` и напрямую через атрибут — значение само ограничится
  диапазоном `0..MaxHealth`.
- При смерти срабатывает `BindableEvent` `model.Died` (аналог `Humanoid.Died`) —
  на него можно повесить дроп лута или зачёт квеста. Если
  `DESTROY_ON_DEATH = true`, модель удалится через 3 секунды.

### Хитбокс по зонам + реакция на попадание

Классический меч игрока бьёт через `Handle.Touched` →
`FindFirstChildOfClass("Humanoid")`, а у юнита Humanoid нет. Поэтому урон
принимается на стороне юнита, **по партам внутри `BodyColliders`** (R15-риг:
`Head`, `UpperTorso`, `LowerTorso`, конечности):

- скрипт ловит взмах оружия (`Tool.Activated`) и ищет **ближайший парт** к
  рукояти оружия (или к игроку). По зоне парта выбирается урон:
  - **голова** (`Head`) → мгновенная смерть;
  - **торс** (`*Torso`, `HumanoidRootPart`) → за `BODY_HITS_TO_KILL` ударов (по умолчанию 4);
  - **конечности** (руки/ноги) → слабее, за `LIMB_HITS_TO_KILL` ударов (по умолчанию 7).
- **Реакция на попадание:** на любой удар юнит вздрагивает (`STAGGER_TIME` —
  замирает); попадание по ноге ещё и замедляет его (`LEG_SLOW_TIME`,
  `LEG_SLOW_FACTOR`).
- На `collider.Touched` не полагаемся (коллизионные группы глушат `Touched`) —
  ищем парт запросом по расстоянию. Работает с любым оружием, без правок в нём.
- Настройки в начале скрипта: `BODY_HITS_TO_KILL`, `LIMB_HITS_TO_KILL`,
  `HIT_REACH = 3.0`, `HIT_DEBOUNCE = 0.35`.
- HP по-прежнему в атрибутах `Health`/`MaxHealth` (для полоски и внешних систем),
  но смертельность теперь задаётся числом ударов, а не «сырым» числом HP.

### Полоска здоровья (HP bar)

Над головой юнита скрипт сам создаёт `BillboardGui` с полоской HP, которая
читает атрибут `Health` (зелёная → красная по мере урона). Видно всем игрокам,
удобно проверять, проходит ли урон. Отключить: `SHOW_HEALTH_BAR = false` в
секции «ПОЛОСКА ЗДОРОВЬЯ».

### Устойчивость на поверхности и разведение

Физический корень — один парт `HumanoidRootPart` (остальные парты висят на нём
как невидимый хитбокс), поэтому контактов с миром меньше и трясёт слабее.

Против подбрасывания в небо `stabilizeOnGround` каждый кадр сверяет нижнюю точку
ног с землёй (raycast). Ноги ищутся по R15-именам (`Foot`/`Leg`):

- просел под пол → плавно поднимает;
- подбросило выше нормы (> `MAX_HOVER_ABOVE_GROUND = 2.5` studs над землёй) →
  жёстко возвращает к земле и гасит вертикальную/угловую скорость;
- в норме → просто не даёт резко взлетать (`MAX_UPWARD_VELOCITY`).

**Против налезания друг на друга** юниты помечаются тегом `RaftMeleeUnit` и при
движении добавляют вектор «прочь от соседей» в радиусе `SEPARATION_RADIUS`
(сила `SEPARATION_STRENGTH`) — они окружают цель, а не слипаются в точку.

- Игрок в радиусе `20` — Корсар замечает игрока и идёт к нему с `Walk`.
- Если игрок после обнаружения убежал дальше `20`, Корсар включает погоню, ускоряется в `1.5` раза и включает `Run`.
- Погоня отключается, когда Корсар снова приблизился к игроку на `5` или меньше.
- Если игрок убежал дальше `35`, Корсар забывает цель и возвращается в `Idle`.
- В радиусе атаки Корсар проигрывает `Attack` и наносит урон.
- Физикой управляет только `HumanoidRootPart`; парты ног/головы/рук — невидимый хитбокс (Massless, без коллизии), который заодно служит ориентиром земли для `stabilizeOnGround`.
