# Корсар

Путь в репозитории: `Юниты/Корсар`.

Папка содержит актуальный серверный скрипт для NPC Корсара в Roblox Studio.

## Файлы

- `CorsairAI.server.lua` — единый скрипт для физики, коллайдеров, анимаций, преследования игрока и атаки.

## Как вставить в Roblox Studio

1. В модели Корсара оставь структуру:

   ```text
   Corsair
   ├─ Script
   ├─ BodyColliders
   │  ├─ HeadCollider
   │  ├─ LeftLegCollider
   │  ├─ LeftHandCollider
   │  ├─ RightHandCollider
   │  ├─ RightLegCollider
   │  └─ TorsoCollider
   ├─ corsair
   ├─ AnimationController
   │  └─ Animator
   ├─ Idle
   ├─ Walk
   ├─ Run
   └─ Attack
   ```

2. Скопируй содержимое `CorsairAI.server.lua` в обычный серверный `Script` внутри модели Корсара.
3. У объектов `Idle`, `Walk`, `Run`, `Attack` должны быть выставлены правильные `AnimationId`.
4. Отключи старые скрипты, которые отдельно приваривали коллайдеры, запускали анимации или двигали Корсара, чтобы не было конфликтов.

## Логика поведения

### Здоровье (HP) без Humanoid

В модель **не нужно** добавлять `Humanoid`. Он ломает этот тип юнита:

- перехватывает анимации у `AnimationController` (у модели должен быть либо
  `Humanoid`, либо `AnimationController`, но не оба сразу) — анимации перестают играть;
- запускает свою физическую state-machine поверх ручного движения
  (`AssemblyLinearVelocity`, `AlignOrientation`, велды) — ломается физика.

Поэтому HP сделано без Humanoid. Если `Humanoid` остался от старых
экспериментов, скрипт сам удалит его при запуске.

- Стартовое HP задаётся константой `UNIT_MAX_HEALTH = 100` в начале скрипта.
- Здоровье хранится в **атрибутах модели**: `Health` и `MaxHealth` (видны во
  вкладке Attributes и реплицируются на клиент — удобно для полоски HP).
- Урон/лечение из других скриптов — через `BindableFunction` внутри модели:
  - `model.TakeDamage:Invoke(20)` — нанести 20 урона (возвращает остаток HP);
  - `model.Heal:Invoke(10)` — вылечить на 10.
- Можно менять `Health` и напрямую через атрибут — значение само ограничится
  диапазоном `0..MaxHealth`.
- При смерти срабатывает `BindableEvent` `model.Died` (аналог `Humanoid.Died`) —
  на него можно повесить дроп лута или зачёт квеста. Если
  `DESTROY_ON_DEATH = true`, модель удалится через 3 секунды.

- Игрок в радиусе `20` — Корсар замечает игрока и идёт к нему с `Walk`.
- Если игрок после обнаружения убежал дальше `20`, Корсар включает погоню, ускоряется в `1.5` раза и включает `Run`.
- Погоня отключается, когда Корсар снова приблизился к игроку на `5` или меньше.
- Если игрок убежал дальше `35`, Корсар забывает цель и возвращается в `Idle`.
- В радиусе атаки Корсар проигрывает `Attack` и наносит урон.
- `LeftLegCollider` и `RightLegCollider` остаются `CanCollide = true` и сталкиваются с землёй, но не с игроком; `MAX_UPWARD_VELOCITY` и `MAX_GROUND_LIFT_PER_HEARTBEAT` ограничивают резкие подлёты на неровной поверхности. Если Корсар просел под пол после пересоздания коллайдеров, скрипт поднимает его по нижней точке ног.
