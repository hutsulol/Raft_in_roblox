# Юниты

Эта папка хранит варианты скриптов для разных NPC-юнитов Roblox Studio.

## Структура

```text
Юниты
├─ Корсар
│  ├─ CorsairAI.server.lua
│  └─ README.md
└─ Пират
   ├─ PirateAI.server.lua
   └─ README.md
```

## Зачем отдельные папки

У разных юнитов могут быть разные:

- имя визуального skinned mesh (`corsair`, `Pirate` и т.д.);
- наборы `Idle`, `Walk`, `Run`, `Attack` анимаций;
- будущие категории занятий/поведения;
- скорость, урон, здоровье, радиусы обнаружения и погони;
- ограничения подлёта на неровной поверхности (`MAX_UPWARD_VELOCITY`, `MAX_GROUND_LIFT_PER_HEARTBEAT`).

Скрипты сейчас используют одинаковую базовую боевую логику, но лежат отдельно, чтобы каждый юнит можно было настраивать независимо.
