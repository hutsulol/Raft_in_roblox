# Пират

Папка содержит актуальный серверный скрипт для NPC Пирата в Roblox Studio.

## Файлы

- `PirateAI.server.lua` — единый скрипт для физики, коллайдеров, анимаций, преследования игрока и атаки.

## Как вставить в Roblox Studio

1. В модели Пирата оставь структуру:

   ```text
   Pirate
   ├─ Script
   ├─ BodyColliders
   │  ├─ HeadCollider
   │  ├─ LeftLegCollider
   │  ├─ LeftHandCollider
   │  ├─ RightHandCollider
   │  ├─ RightLegCollider
   │  └─ TorsoCollider
   ├─ Pirate
   ├─ AnimationController
   │  └─ Animator
   ├─ Idle
   ├─ Walk
   ├─ Run
   └─ Attack
   ```

2. Скопируй содержимое `PirateAI.server.lua` в обычный серверный `Script` внутри модели Пирата.
3. У объектов `Idle`, `Walk`, `Run`, `Attack` должны быть выставлены правильные `AnimationId` именно для Пирата.
4. Отключи старые скрипты, которые отдельно приваривали коллайдеры, запускали анимации или двигали Пирата, чтобы не было конфликтов.

## Логика поведения

- Игрок в радиусе `20` — Пират замечает игрока и идёт к нему с `Walk`.
- Если игрок после обнаружения убежал дальше `20`, Пират включает погоню, ускоряется в `1.5` раза и включает `Run`.
- Погоня отключается, когда Пират снова приблизился к игроку на `5` или меньше.
- Если игрок убежал дальше `35`, Пират забывает цель и возвращается в `Idle`.
- В радиусе атаки Пират проигрывает `Attack` и наносит урон.
- `LeftLegCollider` и `RightLegCollider` остаются `CanCollide = true` и сталкиваются с землёй, но не с игроком; если Пират просел под пол после пересоздания коллайдеров, скрипт поднимает его по нижней точке ног.
