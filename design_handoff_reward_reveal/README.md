# Handoff: Анимация выдачи награды (Reward Reveal) — Roblox

## Overview
Полноэкранный оверлей получения нового предмета: предмет впрыгивает по центру экрана с отскоком, рядом выскакивает золотая звезда, снизу всплывают название предмета и статус («НОВОЕ!» / «ДУБЛИКАТ»), всё висит ~2.3 секунды и плавно исчезает. Без бликов/лучей — чистое появление и пропажа.

## About the Design Files
`Reward Reveal Roblox.dc.html` — дизайн-референс в HTML (открывать в браузере, рядом должен лежать `support.js`). Кнопка «▶ Показать снова» — только для демо, в игре её нет. Задача — воссоздать анимацию в Roblox (Luau): ScreenGui + TweenService.

## Структура (ScreenGui, по центру экрана)
1. **Предмет** — в HTML глиф-заглушка ⚔ (130px). В Roblox: ImageLabel с иконкой предмета или ViewportFrame с 3D-моделью, размер ~230-320px по центру, чуть выше середины экрана.
2. **Звезда** — золотая ★ (#ffd23a) с чёрной обводкой, ~36px, слева-снизу от предмета.
3. **Название** — дисплей-шрифт (Enum.Font.LuckiestGuy для латиницы; для кириллицы FredokaOne/GothamBlack + UIStroke), 40px, белый, чёрная обводка (UIStroke Thickness 2-3) + тень.
4. **Статус** — 30px, той же гарнитурой:
   - «НОВОЕ!» — золотой #ffd23a
   - «ДУБЛИКАТ» — фиолетовый #c86ae8

## Тайминги анимации (перенести в TweenService)
Появление:
- t=0.05s — предмет: scale 0 → 1.18 → 1.0 + поворот −18° → +6° → 0°, длительность 0.55s. В Roblox: Tween Size/Rotation, EasingStyle.Back, EasingDirection.Out (overshoot ~1.18).
- t=0.35s — звезда: scale 0 → 1.4 → 1.0, 0.4s, Back Out.
- t=0.35s — название: сдвиг снизу на 14px + прозрачность 1→0, 0.4s, ease-out (Quad Out).
- t=0.50s — статус: так же, 0.4s.

Удержание: до t=2.8s.

Исчезание:
- t=2.8s — весь блок: scale 1 → 0.8 + прозрачность 0 → 1 (TransparencyTween до 1), 0.5s, ease-in (Quad In). После — Destroy/скрыть.

## Behavior
- Триггер: сервер выдаёт предмет → RemoteEvent клиенту → показать оверлей.
- `duplicate: boolean` определяет статус-строку и её цвет.
- Несколько наград подряд — показывать очередью (следующая после исчезновения предыдущей).
- Оверлей не блокирует управление игроком; клики сквозь (Active = false).
